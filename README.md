One line of awkward small talk from one robot to another in an elevator: its sensors confirm they both pressed 12, neither of them lives on 12, and now they have eleven floors to pretend this was the plan. The program in `main.ts` writes that single line (125 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
